# Data Structures & Algorithms in Python

This repository contains the **code, slides, recordings, and practice material** from my DSA classes for students from non-technical backgrounds.

The classes were conducted through a **non-profit organization based in Silicon Valley** that aims to make coding education accessible to people from non-technical backgrounds in Pakistan.

## Topics Covered

* Stack
* Queue
* Linked List
* Hashmap
* Related concepts, operations, and practice questions

The repository includes the **Python implementations, lecture slides, class recordings, and practice material** for these topics.

The focus was on explaining DSA concepts through simple examples and beginner-friendly Python code.
